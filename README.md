# GCT_FaceRec
Intelligent facial recognition attendance management system using Siamese Neural Networks, FastAPI backend, OpenCV face detection, and mobile interface.
Graduation project developed for Groupe Chimique Tunisien (GCT).

## Overview

This system uses AI-based facial recognition to automate employee attendance tracking.

Main features:

- Face detection using OpenCV
- Siamese Neural Network for facial verification
- FastAPI backend
- Mobile-compatible interface
- Real-time check-in/check-out

## Architecture

- TensorFlow / Keras
- FastAPI
- OpenCV
- Python

## Project Structure

- ai/ → training and model inference
- backend/ → API endpoints
- frontend/ → web interface
- notebooks/ → experimentation
